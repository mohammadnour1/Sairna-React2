# سيرنا — Sairna

موقع تجريبي متكامل لحجز رحلات الحافلات بين المحافظات السورية، مصمّم لتعليم تطوير واجهات الويب.

## التشغيل

1. افتح `index.html` في المتصفح، أو افتح المجلد باستخدام VS Code وامتداد Live Server.
2. لا تحتاج `npm install` ولا Node.js ولا بناء المشروع؛ كل شيء باستخدام HTML وCSS وJavaScript فقط.
3. الخط المستخدم **Cairo** من Google Fonts عند توفر الإنترنت (ويعمل الخط البديل بدون إنترنت).
4. الأيقونات من **Lucide Icons** (إصدار ثابت عبر CDN). يتم تحويلها إلى SVG بعد كل تحديث للصفحة، وتظهر رسومات SVG احتياطية عند انقطاع الاتصال، بدون رموز إيموجي.
5. صفحة التتبع تعرض خريطة OpenStreetMap باستخدام Leaflet عندما تتوفر ملفات المكتبة والإنترنت. عند تعذر ذلك تُعرض خريطة SVG محلية مع محاكاة حركة الحافلة.

## الصفحات

| الرابط | الصفحة |
|---|---|
| `#home` | الرئيسية والبحث عن رحلة |
| `#results` | اختيار الشركة، المواعيد، الأسعار والفلاتر |
| `#booking` | اختيار المقعد، بيانات المسافرين، مراجعة الحجز |
| `#success` | تأكيد الحجز والتذكرة |
| `#trips` | حجوزاتي وعرض التذكرة |
| `#tracking` | التتبّع التفاعلي على الخريطة |
| `#companies` | شركات النقل |
| `#login` / `#register` | تسجيل الدخول وإنشاء حساب |
| `#account` | ملف المستخدم |
| `#about` / `#support` | عن المشروع والمساعدة |

## سيناريو تجربة كامل

- اختر حلب ← دمشق (أو أي محافظتين مختلفتين) وتاريخ الرحلة وعدد المسافرين.
- اختر شركة النقل، ثم الرحلة المتاحة، ثم المقاعد.
- أدخل أسماء وأرقام هاتف *وهمية* في خطوة بيانات المسافرين.
- راجع الحجز، ثم أكّده. إن لم تكن مسجّل الدخول، ادخل باستخدام بريد بصيغة صحيحة وكلمة مرور من 6 أحرف أو أكثر؛ سيتابع النموذج من حيث توقفت.
- افتح «حجوزاتي» لعرض التذكرة، ثم «تتبّع الرحلة» لمشاهدة المحاكاة.

## ملاحظات أمان مهمة

- هذا **تصميم تعليمي تجريبي**. لا توجد API حقيقية، ولا نظام مصادقة أو دفع أو بيع تذاكر.
- الدخول/التسجيل شكلان تفاعليان فقط: لا يُتحقق من كلمة المرور من خادم ولا تُحفظ كلمة المرور.
- تُحفظ بيانات المستخدم التجريبية والتذاكر محلياً داخل `localStorage` في نفس المتصفح. لا تدخل بياناتك الحقيقية أو الحساسة.
- أسماء الشركات وتقييماتها والأسعار والمواعيد والمسافات والمقاعد ومواقع الحافلة محاكاة وليست معلومات فعلية.
- خريطة OpenStreetMap تعرض خلفية جغرافية، أما مسار الرحلة وحركة الحافلة فهما **تقدير/محاكاة** وليسا GPS مباشر.
- هذا نموذج واجهة؛ في أي تطبيق حقيقي يجب ربط المصادقة والحجز والأسعار وتوفّر المقاعد والتتبّع بخادم مع صلاحيات وتحقق ومعاملات آمنة.

## مهام تدريبية مقترحة

- فصل المكوّنات الموجودة في `app.js` إلى ملفات ووحدات قابلة لإعادة الاستخدام.
- استبدال البيانات التجريبية بواجهات `GET /cities`, `GET /companies`, `GET /trips`, `POST /bookings`.
- إضافة واجهات مصادقة حقيقية بـ HTTPOnly cookies أو جلسات آمنة وتحقق من الخادم.
- ربط إشعارات وحالة الرحلة وGPS فعلي من مزود النقل بعد توفر مصدر بيانات مصرح به.

**الهوية**: عربي RTL، خط Cairo، أزرق بحري `#103A4E`، فيروزي `#0AA99B`، خلفيات فاتحة، Dark Mode، تأثيرات Hover خفيفة واستجابة لمختلف الشاشات.

## أسلوب الأيقونات

- استعمل `icon("search", 20)` داخل `js/app.js` بدلاً من كتابة إيموجي أو SVG في كل مكان.
- يتم تحويل أسماء الأيقونات إلى أسماء Lucide الرسمية من خلال `LUCIDE_NAMES` في `app.js`، ويُحدّث العرض عبر `refreshIcons()` بعد إعادة الرسم.
- تحميل مكتبة Lucide غير إلزامي لتشغيل الموقع: عند عدم توفر الإنترنت يظهر SVG متناسق كحل احتياطي.
- يمكنك استبدال رابط CDN بملف Lucide مُحمّل محلياً إذا احتجت الاستغناء عن الإنترنت بالكامل.
